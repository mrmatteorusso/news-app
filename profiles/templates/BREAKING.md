# Breaking and critical profile

Select only unusually consequential developments: war or major escalation, coup, major terrorist attack, assassination of a major public figure, unexpected national leadership collapse, extreme disaster, major bank or sovereign failure, emergency central-bank action, exceptional market crash/rally, or a genuinely major technology event.

Do not enforce a fixed number of stories. Return every distinct event that genuinely qualifies. Multiple simultaneous critical events should all appear, while one event is acceptable when only one qualifies and an empty selection is correct when nothing qualifies.

Configurable financial signals may include approximately:

- Major equity index: ±5%
- Gold: ±5%
- Bitcoin: ±10%
- Ethereum: ±10%

Thresholds are signals, not automatic proof. Consider context and corroboration. If no candidate qualifies, return an empty selection so the interface can state “No major breaking events detected.”

Rank using consequence, breadth, immediacy, source authority, corroboration, and surprise-avoidance value. Routine political argument and ordinary volatility must score low.
